# Desafios - Algorithms

Soluções e documentação dos desafios de algoritmos (HackerRank).

## Estrutura
```
hackerrank/
  NN-nome-do-desafio/
    template.cpp   # código original do HackerRank (antes de resolver)
    solution.cpp   # código resolvido
    README.md      # enunciado, raciocínio, complexidade e testes
    tests/         # N.in (entrada) / N.out (saída esperada)
run_tests.ps1      # compila e roda os testes de um desafio
```

```powershell
.\run_tests.ps1 hackerrank\01-solve-me-first
```
Requer `g++` no PATH.
